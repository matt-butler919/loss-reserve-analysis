Loss Reserve Analysis project

Link to full project - https://docs.google.com/spreadsheets/d/1m86hKpLGwCnKNGVjiyk6MGhfF_zHGysXYgBV6ux1QKU/edit?gid=1334264677#gid=1334264677

Data from Casualty Actuarial Society - https://www.casact.org/publications-research/research/research-resources/loss-reserving-data-pulled-naic-schedule-p

A loss reserve analysis is used to estimate future liabilities for unpaid claims, known as IBNR (Incurred But Not Reported). This project is a loss reserve analysis using both the Chain Ladder and Bornhuetter-Ferguson methods built using publicly available private passenger auto insurance data from the Casualty Actuarial Society Loss Reserve Database across ten accident years from 1998 to 2007. I used a simple R script to filter it to only evaluate one company, IDS Property Casualty Insurance Co, and because the dataset contains fully developed data, I also truncated the dataset to a December 31, 2007 evaluation date. I then organized the cumulative paid losses into a development triangle, calculated age-to-age development factors to measure how losses grow over time, and chained those factors together to project ultimate losses for each accident year. The difference between projected ultimate losses and paid losses to date represents the IBNR reserve. I also calculated ultimate loss ratios by accident year to show whether each year was ultimately profitable. I did this for both the Chain Ladder and Bornhuetter-Ferguson methods, and then finished by comparing the results of each.
